4+ years shipping backend systems at Infosys, now doing an MS in Information Management at the UIUC iSchool. I build AI-powered products end to end — scraping, backend, agent logic, deployment — using Claude Code, LangChain, and FastAPI as daily tools, not buzzwords. ### Featured Work

**[UIUC Course Explorer Data Agent](https://github.com/omkarchougule19/course-explorer-agent)** — [live demo](https://course-explorer-agent.onrender.com/) — a concurrent scraper + FastAPI backend with a LangChain agent that writes and executes its own SQL to answer plain-English questions about UIUC courses.

**[RAG Chatbot System](https://github.com/omkarchougule19/ragSystem)** — a modular end-to-end RAG pipeline (LangChain, ChromaDB, OpenAI) with multi-query retrieval, reciprocal rank fusion, and cross-encoder reranking.

**[Supply Rush](https://github.com/omkarchougule19/supply-rush)** — [live demo](https://supply-rush.onrender.com/) — a full-stack supply-chain simulation game built solo through an AI-accelerated workflow; a professor now uses it to teach students.

**[EV Market Intelligence Analytics System](https://github.com/omkarchougule19/EV-Market-Intelligence-Analytics-System)** — Python ETL pipelines feeding a Power BI star-schema data mart for EV market KPI analysis.
